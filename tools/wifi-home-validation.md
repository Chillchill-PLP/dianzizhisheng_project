## 开发板验收

1. 动画结束后显示四宫格，无自动播放；短按顺序为音乐、电子琴、文件传输、设置，再回到音乐。
2. 每项长按约 1 秒进入；功能内长按返回，原选中位置保留。持续按住与松开均不重复触发；按住 BOOT 开机后松开不产生操作。
3. 进入音乐时首次加载语音和 SD，加载期间长按可返回。检查语音播放/暂停、切歌、电子琴与设置加减音量。
4. 文件传输：连接 `DianZiZhiSheng` / `dzzs2026`，浏览器打开 `http://192.168.4.1/`，上传并下载 WAV 核对文件；返回音乐确认新文件可播放。
5. 测试同名文件、错误格式、传输中长按退出、无 SD 卡、卡满、重复进出模式、播放过音乐后再进入传输。
6. 配置可选 2.4 GHz 路由器 SSID/密码，检查屏幕上的 STA IP；断开路由器后热点仍应可用。

默认单文件最大 64 MiB，播放器最多 16 首，网页最多显示根目录 64 个 WAV。仅传输 WAV 文件，不提供 MP3 解码、实时音频流或 OTA。
